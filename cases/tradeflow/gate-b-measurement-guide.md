# Gate B 中文测量说明

> 当前定级：这是 TRADEFLOW 样本结构调查的工程测量，不是 TITANS 业务全貌验收。即使结果全部通过，也不证明独立认知方法有效，不确认整体业务价值，不授权 V1C。

这不是让你判断代码对不对，而是比较两种查法：

- **原始清单**：只看 Oracle 表结构、约束、字段和注释，不看认知地图。
- **认知地图**：看 Panorama/Object Card、候选、Evidence 和 Unknown 结果。

不需要阅读英文 JSON，也不需要修改 `evaluation_report.json`。

## 四个任务

### 任务一：技术键、业务 Identity、Grain

对象：`OTC_OPTION_PARAMETER`

要回答：

1. 数据库明确声明了什么技术键？
2. 能不能仅凭元数据确认业务 Identity？
3. 能不能确认一行代表什么业务粒度？

当前认知结果：接受 `ID` 为技术 Identity 候选；业务 Identity 未确认；Grain 只保留结构性候选。

### 任务二：对象角色和反证

对象：`POS_FAST_TRS_LEG_CURRENT_POS`

要回答：

1. 它更像事件、历史，还是当前状态快照？
2. 依据是什么？
3. 有没有证据不足或反证？

当前认知结果：接受弱 `SNAPSHOT` 候选，依据是表注释“北上极速腿当前持仓表”；它不是已确认的正式业务角色。

### 任务三：关系层级和方向

范围：`TRADEFLOW`

要回答：

1. 看到的相似结构是不是关系？
2. 有没有 FK、Oracle Dependency 或 SQL Lineage？
3. 如果没有，是否应该保持 `UNKNOWN`？

当前认知结果：保持 `UNKNOWN`；结构相似不等于有方向的业务关系。

### 任务四：无键对象的 Unknown

对象：`TRANS_CSO_HA_TZXX`

要回答：

1. 没有 PK/UK 时，普通索引能不能直接当 Identity？
2. 如果不能，是否应该明确输出 `UNKNOWN`？

当前认知结果：保持 `UNKNOWN`；普通索引不能直接升级为 Identity。

## 只需记录这几项

每个任务分别用“原始清单”和“认知地图”查一次：

| 项目 | 怎么记 |
|---|---|
| 是否完成 | 能否给出结论或正确 Unknown |
| 是否正确 | 结论是否符合上面的当前认知结果 |
| 耗时 | 从开始查到得出结论的秒数 |
| 打开对象数 | 实际打开的表/View/Object Card 数量 |
| 导航步数 | 点击、返回、切换证据的次数 |
| 误导点 | 被错误方向带偏或需要回退的次数 |

你可以直接用中文把结果发给我，例如：

```text

任务二：原始清单无法判断；认知地图判断为 SNAPSHOT，依据表注释。
```
