## Why

现有 TRADEFLOW 表级分类已经能够生成结构邻域和多维候选标签，但真实结果表明，结构相似、预设词表和标签传播无法直接回答“这张表承载什么、与哪些表共同完成什么、在表组中承担什么职责”。同时，字段语义与固定 Wiki Tree 已形成可重放的辅助证据，适合在不覆盖既有结果的前提下建立独立的表级语义地图。

2026-08-12 的强制替代评审将首轮实现处置为 `REWORK`：当前结果虽然完整保留 477 张表和工程边界，但职责候选仍主要由固定词表及名称/注释触发，字段尚未支持具体表级断言，配置调查组被呈现为业务协作组，且 Gate 可以在没有业务关系时空通过。本 Change 因此继续保留原工程历史，并新增针对这些读者价值缺口的返工范围。

## What Changes

- 新增表级语义 Projection，以固定 TRADEFLOW Physical Facts、现有表级结构/分类结果、固定 Wiki Tree 与字段侧候选结果为只读输入；表是唯一分类主体，字段只用于支持、区分或反驳表级候选。
- 为每张主体表生成可追溯的表语义画像，分别保存业务上下文、业务锚点、表职责、表组成员关系、表间语义关系、Evidence、Counterevidence、Method、Review Status、Conflict 与 Unknown。
- 明确区分业务协作表组、物理变体组和结构邻域：业务协作表组允许结构不同的表围绕同一业务对象或过程协作；物理变体组折叠日期后缀、备份和迁移版本候选；现有 Schema Matching/Leiden 结果仅作结构调查线索，不自动成为业务表族或独立业务证据。
- 以 233 张当前主体表作为首轮表语义分析范围，同时纳入其余 244 张后缀表的物理变体候选；名称规则不能确认变体关系时保留独立对象、Conflict 或 Unknown，不得静默排除。
- 从固定 Wiki Tree 标题和路径进行有界候选召回；目录父子位置只作导航和文档场景证据。仅当固定正文明确提表、描述用途或表间协作时，才形成带来源的表级实现/关系候选，且不自动成为已确认业务事实。
- 字段名称、注释、类型、键及独立字段语义候选作为辅助证据，不进行字段标签多数投票，不把字段上下文机械继承为表标签，并按根来源阻止“表名推字段、字段再证明表”的循环自证。
- 使用表级 Assertion 统一治理候选标签与关系，保留直接证据、传播/结构线索、反证和人工处置；方法分数只用于方法内排序，不显示为正确概率，不自动产生 `ACCEPTED`。
- 先以 TRS、期权、当前/历史持仓、参数/日志/报表反例和映射类表五组调查卡验证信息模型；模型 Gate 通过后再生成“业务上下文 → 业务锚点/协作表组 → 表职责 → 表”的浅层导航及多维筛选。
- 将种子词表与语料发现候选分层：种子只提供召回和规范化线索，未命中既有词表的新职责表达仍须保留；评审词表不得被实现成封闭枚举。
- 将字段证据关联到具体表级职责、上下文、锚点或关系 Assertion，并明确其 `SUPPORTS`、`DISTINGUISHES`、`COUNTERS` 或 `NOT_USED` 作用；字段摘要计数本身不构成支持。
- 将配置中的 TRS、期权等集合降级为调查夹具；只有成员职责充分且组内形成有证据的连通语义关系图时，才生成业务协作组候选。
- 收紧模型 Gate，使关键表无职责、调查组无语义关系、Wiki预算顺序偏置、字段证据未落到断言及仅校验“已输出关系”的空通过均成为失败。
- 允许在用户逐项授权后冻结单行、无业务主键值的测试库聚合核验结果，用于回答特定关系的键匹配率与基数；聚合结果只能形成带快照边界的关系候选，不得升级为数据库外键、生产规则或业务验收。
- 本 Change 不修改字段语义 Canonical/Projection，不重新运行或扩大现有字段侧 Change，不读取业务数据行，不建立正式企业本体，不把局部表组推广到其他 Schema，也不以候选覆盖率代替读者验收。

## Capabilities

### New Capabilities

- `table-semantic-map`: 定义表语义画像、业务协作表组、物理变体组、结构邻域边界、表级候选标签与关系、字段/Wiki辅助证据、断言治理、模型 Gate 和读者导航 Projection。

### Modified Capabilities

- `cognition-delivery-governance`: 授权在固定 TRADEFLOW、固定 Wiki Tree 和既有字段/分类运行范围内构建独立的候选表语义地图，同时继续禁止自动 Canonical 回写、全 Panorama 深度语义扩展、正式本体和业务验收替代。

## Impact

- 影响新的表语义派生模块、类型化 JSONL/Parquet 结果、配置、CLI、Manifest、调查卡、静态审阅页面及相关测试；现有 Physical Facts、表级分类结果和字段侧结果保持只读且不原地修改。
- 复用现有 Python、Parquet/JSON/YAML、内容哈希、Panorama Object Card、固定 Wiki 缓存与字段语义物理 ID；不引入 PostgreSQL、Neo4j、向量数据库、远程 Worker、业务数据行读取或新的外部 Provider 授权。
- `build-bounded-evidence-foundation` 继续提供结构相似信号、结构邻域和候选分类诊断，但其高覆盖候选不被本 Change 解释为业务表语义已经成立。
- 首轮只处理 `TITANS_TRADEFLOW` 固定运行；其他 Schema、全 Wiki 正文、LLM 外发和方法泛化均需独立授权。
- 首轮替代评审结论保持 `REWORK`，直到返工后的五组调查卡和强制替代评审给出新的处置；该处置仍不等于用户业务验收。
