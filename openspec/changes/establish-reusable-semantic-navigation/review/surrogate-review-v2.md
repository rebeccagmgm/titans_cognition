# OTC 衍生品语义导航 V2 审阅报告

## 工程审阅结论

`ACCEPT_WITH_UNKNOWNS`

这表示：当前方法可以作为受限原型继续验证，但不表示业务验收，也不表示可以替换现有页面或对所有 Schema 扩大推断。

## 已检查内容

- 正例：名义本金、交易、持仓、交易对手、保证金等概念的详情投影
- 歧义例：生命周期与结算、主体与角色的重叠
- 反例：仅凭字段后缀、Wiki 目录或名称相似进行归类
- 复用性：同一属性轴可被交易、合同、持仓等不同概念引用
- 未知状态：无法确定的概念保留 `UNKNOWN_BUSINESS_CONCEPT`
- 冲突状态：多业务区域候选保留 `MULTI_AREA_CANDIDATE`

## 当前证据边界

TRADEFLOW 共观察到 1375 个概念：12 个单区域候选、1 个跨区域冲突、1362 个未知。未知数量较高，说明当前业务词种子和证据映射仍不足；它不能被解释为业务概念不存在。

Wiki 只提供上下文候选，不单独生成业务层级、字段属性或业务关系。

当前处置为：`REVIEW_REQUIRED`

在用户明确 `ACCEPT` 前，保持现有字段语义地图不变，禁止将本原型发布为全局业务分类。
