# 字段语义导航：用户审阅入口

这页就是本轮需要审的内容。你不需要先看代码，也不需要逐个核对所有字段。

## 一句话判断

我们准备把现有“按字段名称堆成一棵树”的方式，改成：

> 用 OTC 衍生品业务骨架做入口；业务概念、属性表达、字段属性/限定和物理表字段分层展示；证据不足的内容保留待确认。

## 请直接回答

1. 一级业务区域是否合理：参与主体、产品与标的、询价/订单/交易、合同与结构、生命周期、持仓与风险、估值与履约保障、执行/清算/结算、参考配置、运营报表/数据加工？
2. 是否同意“名义本金”下面分为初始/动态等属性表达，同时把金额、币种、时点、状态作为可复用字段属性或限定，而不是继续混在一层？
3. 是否同意证据不足的概念显示为 UNKNOWN，不强制归类？
4. 如果以上认可，是否同意进入现有字段语义地图页面的替换设计？

## 可选结论

- `ACCEPT`：进入页面替换设计
- `REWORK`：方向认可，但需要修改哪些一级区域或分层边界
- `STOP`：不采用这套抽象
